# Forkcast

Personal calorie tracker web app (plain HTML/CSS/JS, no build). Read `PROGRESS.md` first: it has the file map,
data model, finished features, and how to test and publish.

- Ask for the exact feature or file; `app.js` is split into `// ---------- Section ----------` blocks.
- Test in the browser pane via the `forkcast` launch config, then clear test data from localStorage.
- On every release: bump `CACHE` in `sw.js`, upload changed files to GitHub (see PROGRESS.md), confirm the live site.
- At the end of each feature, update PROGRESS.md.
